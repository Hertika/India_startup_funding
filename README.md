# India Startup Funding Analysis (2015–2026)

## 📌 Project Overview

This project explores Indian startup funding trends from 2015 to 2026 using Microsoft Excel, SQL (MariaDB), and Power BI.

The objective is to analyse funding patterns across years, sectors, cities, and investment stages, and identify meaningful insights from the available dataset.

## 🎯 Project Objectives

- Analyse year-wise startup funding trends.
- Identify the leading sectors by funding.
- Explore funding distribution across major Indian cities.
- Understand funding patterns across investment stages.
- Examine the relationship between startup news mentions and funding.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data cleaning, standardisation, validation, formulas and Pivot Tables.
- **SQL (MariaDB)** – Data validation and exploratory analysis.
- **Power BI** – Interactive dashboard, KPI cards, charts and slicers.
- **Power BI Service** – Publishing and viewing the interactive report.

## 🔍 Project Workflow

1. **Data Collection:** Collected startup funding records for analysis.
2. **Data Preparation:** Cleaned and organised the dataset in Excel, standardised city names, and checked missing values and duplicates.
3. **SQL Analysis:** Analysed funding trends by year, sector, city and investment stage.
4. **Data Visualisation:** Created an interactive Power BI dashboard to present key findings.
5. **Publishing:** Published the report using Power BI Service.

## 📊 Key Findings

- **Highest Funding Year:** 2021, with approximately **$13.23 billion** in recorded funding.
- **Leading Sectors:** Consumer, Retail and Fintech.
- **Top Funding Cities:** Bengaluru, Mumbai, Gurugram and New Delhi accounted for approximately **79.2%** of recorded funding.
- **Funding Stages:** Undisclosed funding stages represented approximately **50.39%** of recorded funding.

## 📈 Dashboard

The Power BI dashboard includes:

- KPI cards highlighting key funding metrics.
- Year-wise funding trends.
- Sector-wise funding distribution.
- City-wise funding analysis.
- Funding stage analysis.
- News mentions compared with funding trends.
- Interactive slicers for exploring the data.

## ⚠️ Data Limitations

- The dataset contains **5,006 records**, representing approximately 37% sample coverage.
- **975 records** have missing funding amounts.
- 2026 data is partial and covers records only up to June 11, 2026.
- Findings represent the available dataset and should not be interpreted as the complete picture of Indian startup funding.
- The comparison between news mentions and funding shows association patterns, not causation.

## 💡 Key Learning

This project helped me practise data preparation, SQL-based analysis, data visualisation, and insight communication. It also reinforced the importance of validating data and understanding its limitations before drawing conclusions.
